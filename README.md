# 🤖 Telegram-бот с AI для строительной отчетности мастера (М-100)

Интеллектуальный ассистент для автоматизации ежедневной отчетности прораба/мастера со строительного объекта. Мастер надиктовывает голосовое сообщение или пишет текст в свободной форме на профессиональном сленге — бот структурирует данные, сопоставляет работы со сметной спецификацией, проводит верификацию и синхронно записывает факт выполнения в **Google Таблицу** и **Битрикс24**.

---

## 🌟 Реализованные возможности

- ✅ **Прием свободной речи (текст и голос):** понимание профессионального строительного сленга (*«медь 6-ка»*, *«кабель 3 на 2,5»*, *«хомуты под фреон»*).
- ✅ **Разрешение контекстных ссылок (анафор):** фраза *«медь 6-ку 15 м и 9-ку 15 м, изоляцию на них столько же»* корректно генерирует отдельные позиции изоляции для каждого диаметра.
- ✅ **Двухэтапный гибридный матчинг:** математическая защита от галлюцинаций LLM при похожих наименованиях.
- ✅ **Интерактивная верификация (Human-in-the-Loop):** показ карточки отчета с инлайн-кнопками *[Подтвердить]*, *[Изменить объем]*, *[Удалить]*, *[Отмена]*.
- ✅ **Обработка спорных позиций и неоднозначностей:** если назначение не указано (например, *«Просверлили 12 отверстий»*), бот **не угадывает**, а предлагает инлайн-кнопки выбора: *[Под фреон (ост. 18)]* или *[Под дренаж (ост. 26)]*.
- ✅ **Динамический справочник сметы:** считывание каталога напрямую из Google Sheets без хардкода в Python с умным кэшированием (TTL) и командой `/sync`.
- ✅ **Суммирование при повторном отчете за день:** если мастер присылает несколько отчетов за один день, новые объемы прибавляются к ранее внесенным.
- ✅ **Синхронизация с Битрикс24:** автоматическое создание структурированной задачи в Битрикс24 с детализацией работ.
- ✅ **(Плюс) Контроль остатка по смете:** визуальное предупреждение ⚠️ при превышении планового остатка сметы.
- ✅ **(Плюс) Ответы на вопросы:** обработка запросов вида *«Сколько осталось по кабелю 3х2,5?»*.
- ✅ **(Плюс) Автономный режим тестирования (Offline Mock):** бот полноценно функционирует и проходит 100% тестов даже без подключения внешних платных API.

## 🚀 Быстрый запуск

### 1. Требования
- Python 3.11+
- (Опционально) Docker & Docker Compose

### 2. Клонирование и установка зависимостей
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd M-100

# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows PowerShell)
.venv\Scripts\Activate.ps1
# (или Linux/macOS: source .venv/bin/activate)

# Установка зависимостей
pip install -r requirements.txt
```

### 3. Настройка переменных окружения (`.env`)
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
- `TELEGRAM_BOT_TOKEN`: токен от [@BotFather](https://t.me/BotFather).
- `OPENAI_API_KEY`: API-ключ OpenAI (для Whisper и LLM).
- `GOOGLE_SERVICE_ACCOUNT_FILE`: путь к JSON-ключу сервисного аккаунта Google Cloud.
- `GOOGLE_SPREADSHEET_ID`: ID вашей Google Таблицы (из URL таблицы).
- `GOOGLE_SHEET_URL`: прямая ссылка на таблицу для кнопки в боте.
- `BITRIX24_WEBHOOK_URL`: URL входящего вебхука Битрикс24 (с правами на `tasks`).

> **💡 Подсказка:** Если ключи Google Sheets или Битрикс24 не указаны, система автоматически переходит в режим эмуляции (использует локальный каталог сметы и логирует записи), что позволяет моментально оценить работу бота.

### 4. Запуск тестов
```bash
pytest -v
```
Все 10 модульных и интеграционных тестов должны завершиться со статусом `PASSED`.

### 5. Запуск бота
```bash
python main.py
```
Либо через Docker Compose:
```bash
docker compose up -d
```

## 🛠 Настройка внешних интеграций

### Google Sheets API
1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект и включите **Google Sheets API** и **Google Drive API**.
2. Создайте **Service Account**, сгенерируйте JSON-ключ и сохраните его в `data/service_account.json`.
3. Скопируйте email сервисного аккаунта (`xxx@xxx.iam.gserviceaccount.com`).
4. Откройте вашу Google Таблицу и предоставьте этому email доступ с правами **«Редактор»**.
5. Укажите ID таблицы в `GOOGLE_SPREADSHEET_ID`.

### Битрикс24 REST API
1. Зайдите в ваш портал Битрикс24 $\rightarrow$ раздел **«Разработчикам»** $\rightarrow$ **«Другое»** $\rightarrow$ **«Входящий веб-хук»**.
2. В правах доступа отметьте:
   - **Задачи (tasks)**
   - **Пользователи (user)**
3. Скопируйте сгенерированный URL вебхука вида `https://b24-xxxx.bitrix24.ru/rest/1/yyyy/` в переменную `BITRIX24_WEBHOOK_URL`.

## 🧠 Описание AI-подхода и сопоставления позиций

### 1. Как устроено сопоставление
Вместо ненадежного одноэтапного промпта применен **Two-Stage Hybrid Matcher**:
1. **Этап 1 (Извлечение сущностей):** LLM (через Structured Outputs / JSON Schema) нормализует сленг, выделяет числовые объемы и раскрывает контекстные ссылки (*«на них столько же»* $\rightarrow$ формирует две строки изоляции под оба диаметра трубы).
2. **Этап 2 (Детерминированный матчер):**
   - Точный поиск по критическим атрибутам (диаметры `6.35`, `9.52`, `12.7`, сечения кабелей `3х2.5`, `3х1.5`, номиналы автоматов `16А`, `20А`, `32А`).
   - Fuzzy Token Matching (`RapidFuzz.token_set_ratio`) для ранжирования оставшихся кандидатов.
   - Фильтрация по совпадению единиц измерения (`м`, `шт`, `компл`).

### 2. Что делать, если LLM ошиблась или есть неоднозначность
1. **Порог уверенности:** Если лучший кандидат набрал score < 75% или отрыв от второго кандидата < 10 пунктов, бот **не угадывает**, а выдает инлайн-кнопки выбора мастером.
2. **Идентичные строки (коллизии):** В смете есть две позиции *«Сверление отверстий Д80 L=0,5м»* (строка 44 — под фреон, строка 45 — под дренаж). Если мастер не уточнил назначение, бот явно запрашивает выбор одной из строк.
3. **Человеческий контроль (Human-in-the-Loop):** Ни одна запись не попадает в таблицу без нажатия кнопки *«✅ Подтвердить и записать»*. Мастер всегда может нажать *«✏️ Изменить объем»* или *«🗑 Удалить позицию»*.

### 3. Ограничения подхода
- **Шумная аудиозапись:** при сильном производственном гуле перфоратора Whisper может исказить цифры. Для этого мастер видит текстовую расшифровку перед подтверждением.
- **Новые непредвиденные материалы:** если мастер назовет материал, которого нет в смете, бот пометит позицию как `НЕ СОПОСТАВЛЕНО` и предложит пропустить или ввести вручную.

## 🤖 Использование AI-инструментов в разработке

- **Архитектурное проектирование:** формулирование вариантов декомпозиции и анализ рисков проводились в роли Senior Software Architect.
- **Генерация regex-эвристик и тестовых сценариев:** AI использовался для построения карты гомоглифов (замена латинских символов `T`, `p`, `y`, `u` на кириллицу) и генерации тестовых наборов данных по ТЗ.
- **Верификация кода:** Все сгенерированные компоненты проверены строгим набором из 10 автоматических pytest-тестов, охватывающих крайние случаи (дубликаты названий, отсутствие ID, опечатки в смете, превышение лимитов).

## 📹 План видеозаписи для подтверждения интеграции с Битрикс24 (1–3 мин)

1. **0:00 – 0:30:** Демонстрация исходного состояния: открыта тестовая Google Таблица (столбец за сегодня пуст) и открыт портал Битрикс24 (список задач пуст).
2. **0:30 – 1:15:** Отправка боту голосового/текстового сообщения: *«Сегодня проложили медь 6-ку 15 м и 9-ку 15 м, изоляцию на них столько же, кабель 3х2,5 — 56 м, поставили 10 хомутов под фреон»*.
3. **1:15 – 1:45:** Демонстрация распознанной карточки в Telegram, проверка объемов и нажатие кнопки *«✅ Подтвердить и записать»*.
4. **1:45 – 2:30:** Переход в Google Таблицу — показ добавленных объемов в строках соответствующих позиций. Переход в Битрикс24 — показ созданной задачи со структурированным списком выполненных работ.
