# Telegram-бот строительного учета мастера (М-100)

Интеллектуальный Telegram-бот для автоматизации ежедневной строительной отчетности прораба/мастера со строительного объекта. Бот принимает отчеты о выполненных работах в свободной форме (голосом или текстом), извлекает наименования и объемы, сопоставляет их со сметной спецификацией и после подтверждения синхронно фиксирует факт выполнения в Google Таблице и Битрикс24.

---

## Техническое задание

Согласно исходному техническому заданию проект реализует:

1. **Прием сообщений в свободной форме:** поддержка текстовых и голосовых сообщений на строительном сленге (_«медь 6-ка»_, _«кабель 3 на 2,5»_, _«хомуты под фреон»_).
2. **Извлечение и сопоставление:** распознавание работ и объемов, сопоставление с позициями спецификации с учетом единиц измерения и разрешение контекстных ссылок (_«изоляцию на них столько же»_).
3. **Интерактивное подтверждение (Human-in-the-Loop):** отображение распознанного списка перед сохранением с возможностью изменить объем, удалить позицию или добавить новую работу.
4. **Запись в Google Таблицу:** внесение объемов в столбец с текущей датой напротив соответствующих позиций (с автоматическим созданием столбца даты, если его еще нет).
5. **Разрешение неоднозначностей:** если позиция не распознана или найдено несколько подходящих строк сметы, бот запрашивает уточнение у мастера кнопками, а не угадывает.
6. **Исправление данных за сегодня:** поддержка режимов накопления (суммирование нового объема с имеющимся) и перезаписи (исправление уже внесенного значения за сегодня).
7. **Просмотр таблицы:** предоставление кнопки-ссылки на Google Таблицу после внесения данных и по команде `/sheet`.
8. **Интеграция с Битрикс24:** создание задачи через входящий вебхук REST API (`tasks.task.add`) со структурированным описанием выполненных работ.
9. **Динамический справочник позиций:** каталог сметы загружается напрямую из таблицы с кэшированием, а не прописывается в коде.
10. **Дополнительные возможности (плюсы из ТЗ):**
    - Распознавание голосовых сообщений через Whisper.
    - Предупреждение при превышении объема над остатком по смете.
    - Ответы на вопросы об остатках (например, _«Сколько осталось по кабелю 3х2,5?»_).

## Технологический стек

- **Язык программирования:** Python 3.11+
- **Telegram Bot Framework:** aiogram 3.x (асинхронная архитектура, FSM, роутеры)
- **AI & STT:** Groq Whisper-Large-v3-Turbo / OpenAI Whisper (распознавание речи), OpenAI GPT-4o-mini / Groq (извлечение сущностей)
- **Нечеткий поиск и сопоставление:** RapidFuzz, Regular Expressions
- **Интеграции:** Google Sheets API v4 (gspread), Битрикс24 REST API (httpx)
- **Валидация и конфигурация:** Pydantic 2, Pydantic Settings
- **Тестирование:** pytest, pytest-asyncio

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd M-100
```

### 2. Создание и активация виртуального окружения

- **Linux / macOS:**
  ```bash
  python -m venv .venv
  source .venv/bin/activate
  ```
- **Windows (PowerShell):**
  ```powershell
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  ```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск тестов

```bash
pytest -v
```

### 5. Запуск бота

```bash
python -m src.bot.bot
```

### Запуск через Docker Compose (опционально)

```bash
docker compose up -d --build
```

## Основные функции и возможности

- **Прием голоса и текста:** обработка голосовых заметок Telegram (OGG/Opus) и текстовых сообщений мастера на строительном сленге.
- **Двухэтапный гибридный матчер:** извлечение сущностей (NER) и атрибутивная фильтрация с защитой от галлюцинаций.
- **Интерактивное управление черновиком:** инлайн-кнопки подтверждения, изменения объема, удаления и добавления позиций прямо в чате.
- **Двухрежимная фиксация:** раздельные кнопки «Записать (+к сегодня)» (суммирование) и «Перезаписать сегодня» (исправление).
- **Контроль сметы:** предупреждение ⚠️ при превышении планового остатка сметы.
- **Q&A режим:** информирование об остатках по смете по текстовому запросу без перехода к созданию отчета.
- **Отказоустойчивость:** автоматический локальный парсер сленга при недоступности внешних AI API, нормализация OCR-опечаток и гомоглифов сметы.
